# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Harness Bridge, please report it privately:

1. **Do not create a public GitHub issue.**
2. Send an email to `sukumar.rtg@gmail.com` with:
   - Description of the vulnerability and potential impact.
   - Minimal steps or proof-of-concept to reproduce the issue.
   - Any suggested mitigations or patches.
3. You can also report via [GitHub Private Vulnerability Reporting](https://github.com/sukumar1210/harness-bridge/security/advisories/new).

Maintainers will acknowledge receipt within 48 hours and coordinate a patch and release before public disclosure.
